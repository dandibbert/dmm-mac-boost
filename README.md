# Still

原生 macOS 页游浏览器。使用 AppKit 和系统 WebKit，不附带 Chromium、Electron、Node.js 或第二套浏览器。此分支的工作树从空树创建，应用代码和资源独立编写。

## 直接使用应用

打开本仓库 **Actions → Build Still → 已成功的构建 → Still-macOS-universal**。下载产物，解压得到 `Still-macOS-universal.zip`，再解压得到 `Still.app`。这是已经编译完成的应用，不需要在自己的电脑安装开发环境或编译源码。

最低 macOS 14。一个应用包同时包含 Apple Silicon 和 Intel 可执行文件。当前包使用本地签名；系统首次打开时可能要求在“隐私与安全性”中明确允许该应用。

## 浏览器能力

- 多标签、多窗口、固定和排序、拖出窗口、跨窗口移动、恢复关闭的标签。移动已有标签保留原 WebView，不重新加载游戏。
- 地址栏、地址补全、搜索、前进后退、刷新与忽略缓存刷新、停止加载、历史记录、书签和筛选侧栏。
- 原生页面查找、缩放、打印、网页归档、页面截图、文件上传和下载管理。下载可以暂停、继续或重试，并在 Finder 中显示。
- 内置 Web Inspector、Console、Sources 和元素选择器。原生页面级静音不以暂停媒体或暂停游戏代替。
- JavaScript 对话框、HTTP 身份验证、网站新窗口、外部应用链接确认、摄像头与麦克风请求确认。
- 会话地址恢复、按游戏地址保存偏好、网站数据清理、设置文件损坏保护。登录数据只属于 Still，不读取其他浏览器的 Cookie。

界面使用紧凑工具栏、横向标签和可隐藏侧栏，遵循系统明暗外观。没有性能仪表盘、持续截图预览或遥测服务。

## 运行模式

| 模式 | 页面 | 内存 |
| --- | --- | --- |
| 常速 | 维持所选页面的原生调度、窗口执行可见性与应用活动 | 保留运行中的游戏 |
| 节能 | 交还系统后台调度，游戏可能变慢或暂停；不重载 | 不保证释放 |
| 休眠 | 明确卸载页面，恢复时重新加载 | 可以释放页面资源 |

常速和节能直接作用于现有会话，不创建第二份页面。常速模式不替换 `requestAnimationFrame`，不伪造 JavaScript 动画帧计数。原生 WebKit 可选接口统一封装在 `Bridge.m`，先检查接口是否存在。

“有常速标签时防止 Mac 自动睡眠”是独立选项，默认关闭。它不要求显示器一直亮着。整机实际进入睡眠后，游戏无法继续运行。

关闭标签或窗口会结束对应游戏；仍在常速运行时会提示。`⌘Q` 退出前也会确认运行中的游戏和下载。

## 游戏专注

检测页面中的 canvas 和 iframe，置信不足时不自动选择。使用原生裁切和等比缩放，不复制 iframe、不改变其地址、不替换游戏的浏览上下文。工具栏可以切换完整页面、自动识别或手动框选。

自动识别并非所有网站布局的保证。游戏区域超出当前页面可见范围，或页面依赖视口尺寸重新布局时，可能需要调大窗口、调整页面缩放或手动框选。原生登录和权限对话框出现时退出裁切，避免隐藏关键提示。

## 已执行的验证

GitHub Actions 在 macOS 15.7.9 上完成双架构编译、应用包签名检查，以及 30 项原生集成检查。检查实际启动应用，不只是语法检查，包括：

- 连续切换运行模式后，页面标识、WebView 和导航代数保持不变。
- 前台、后台标签、最小化状态下，原生 canvas 动画和普通计时器的推进情况。
- 最小化状态直接切为节能，再切回常速，无需先恢复窗口或重新加载。
- 原生静音位、开发者工具、页面查找、关闭其他标签、显式休眠与恢复。
- 通过 WindowServer 截图检查实际窗口是否显示游戏，而非只检查网页截图 API 返回非空图片。

一轮已完成的本地测试页观测：前台约 59.97 FPS，后台标签约 60.92 FPS，最小化约 59.58 FPS；最小化切为节能后为 0 FPS，直接切回常速后约 59.72 FPS。每次构建的独立报告与实际界面截图在 `Still-test-results` 产物中。

**这些是合成测试页的结果，不是已登录实际 DMM 游戏的测试结果。** 尚不能据此保证每款游戏的主动失焦暂停逻辑、每个系统版本、切换桌面以及长时间运行都已验证。应用内“运行诊断”明确区分用户选择的策略、可用的原生能力和采样结果，不显示未经测量的“100% 已验证”。

运行中的游戏本身仍需要脚本堆、纹理和渲染资源。应用减少额外运行环境与重复页面，不承诺未经对照测量的内存节省比例。

## 数据和安全

设置、书签、历史记录保存在 `~/Library/Application Support/Still/state.json`。写入采用原子替换，无法读取的原文件不会被自动覆盖。WebKit 站点数据保存在本应用的数据存储中。

详细采样默认关闭，仅在诊断窗口启动后执行，关闭窗口停止。诊断报告去除地址中的账户信息、查询参数和片段。没有向远端上传页面、Cookie 或诊断数据的代码。

此版本没有扩展商店或跨浏览器密码库导入，也不关闭 WebKit 的同源安全检查、证书校验或其他浏览器的保护设置。
