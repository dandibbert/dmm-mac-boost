# Pagekeep Native

原生 macOS 页游浏览器，AppKit / SwiftUI + 系统 WebKit，macOS 14 及以上，Apple Silicon / Intel 通用。本分支工作树只有本次重新编写的原生程序及测试，没有旧版应用、Electron 或附带浏览器。

## 下载与运行

打开 Actions 中本分支最新成功的 **Pagekeep Native**，下载 **Pagekeep-macOS-universal**。解压其中的应用压缩包，把 `Pagekeep.app` 放入应用程序文件夹后打开。不需要安装构建工具或下载源代码。第一次被系统拦截时，可以在“系统设置 → 隐私与安全性”允许此应用打开。

## 浏览器操作

横向标签栏和地址栏；前进、后退、刷新、忽略缓存刷新、页面查找、缩放、多窗口、标签排序和固定、恢复关闭标签、书签、历史记录、会话恢复、下载、上传、打印及 Web Inspector。支持登录弹窗、JavaScript 对话框、HTTP 身份验证和按网站保存摄像头／麦克风选择。

每个标签独立切换常速 / 节能，并可单独静音。休眠会卸载页面，恢复需要重新加载；切换常速 / 节能则保留当前页面。地址栏只有明确按回车时才导航，切换焦点、输入法确认或打开检查器不会主动刷新游戏。

游戏专注采用原生视图裁切，保留原页面、iframe 与登录状态。不会复制游戏，或把 iframe 地址拿出来重新打开。无法确定区域时可以手动选择候选区域。

常用快捷键：⌘L 地址栏、⌘T 新标签、⌘R 刷新、⌘F 查找、⌥⌘I 检查器、⇧⌘M 静音、⇧⌘F 专注、⌥⌘B 常速／节能。

## 后台实现

常速模式结合应用活动声明、可检测的 WebKit 原生调度控制及后台原生渲染视图。切换到后台、最小化或隐藏应用时，现有游戏视图进入屏幕外的非交互渲染窗口；返回前台时移回原浏览器窗口。不新增游戏实例、不读取别的浏览器会话，不抢占键盘或鼠标。节能模式会释放对应的后台渲染位置，交还 WebKit 的普通后台调度。

这一实现不伪装 `document.hidden`，也不替换网站的动画 API。检测脚本位于隔离的 JavaScript 内容世界，仅按需观察计时器和动画回调。

静音、内置 Inspector 和部分调度控制使用经过运行时检查的 WebKit 非公开接口；系统不支持时会提示。可单独启用防止 Mac 空闲睡眠，但不会强制显示器常亮。手动睡眠或合盖休眠仍然会停止游戏。

## 已完成的云端验证

GitHub Actions 的 macOS 15 环境中，通过 9 项 Swift 基础测试、10 项 JavaScript 回归测试、arm64 / x86_64 编译、应用签名结构验证，以及真实 WKWebView 集成测试。只有测试通过才上传应用压缩包。

同一构建的短时合成游戏主循环测试，每种状态约 7 秒：

| 状态 | 实测动画主循环 |
|---|---:|
| 前台单页面基准 | 59.19 Hz |
| 三个游戏页面同时在后台 | 58.85–58.99 Hz |
| 最小化窗口 | 60.03 Hz |
| 隐藏整个应用 | 60.04 Hz |
| 窗口完全被另一窗口遮挡 | 59.72 Hz |

最低后台结果为前台基准的约 99.4%。主页面、同源 iframe 和跨源 iframe 的探针均正常返回。另验证了连续 200 次模式切换不刷新、后台节能／常速切换释放并恢复渲染视图、专注不重建 iframe、真正的页面静音及内置 Inspector。网页截图使用 WebKit 的原生截图 API，而非仅包含浏览器外壳的 AppKit 缓存。

这些是本次 CI 的合成场景结果，不是所有 DMM 游戏已经长时间实测通过的承诺。实际游戏、其他桌面、显示器关闭、机器资源压力及内存相对 Arc 的差异，仍需实机验证。主动在失焦时暂停的游戏也可能需要进一步适配。

完整日志、调度报告和截图位于同一构建的 **Pagekeep-test-evidence**。

## 本地数据

数据只属于本应用，不读取其他浏览器的登录信息。网站权限需要明确确认；设置中可以撤销已保存的设备权限选择。没有自动上传页面、密码或诊断。书签、历史和会话存于本机 Application Support；异常存储文件会先保护性备份，避免无声覆盖。
