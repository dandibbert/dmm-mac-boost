# Pagekeep Native

原生 macOS 页游浏览器，AppKit / SwiftUI + 系统 WebKit，要求 macOS 14 或更新版本。本分支工作树仅包含此次新写的原生程序及其测试，没有旧版应用、Electron 或附带浏览器。

## 运行

在 GitHub Actions 选择本分支最新成功的 **Pagekeep Native**，下载 **Pagekeep-macOS-universal**，解压其中的应用压缩包，将 `Pagekeep.app` 放入应用程序文件夹。无需本机构建。应用为本地测试用途的 ad-hoc 签名版本，不涉及商业分发。

## 操作

标准标签栏与地址栏，支持前进、后退、刷新、页面查找、缩放、多窗口、标签排序和固定、书签、历史记录、会话恢复、下载、上传、打印及 Web Inspector。每个标签可以切换常速 / 节能，并单独静音。休眠会卸载页面，恢复需要重新加载；切换常速 / 节能则保留当前页面。

游戏专注通过原生视图裁切保持原页面、iframe 与登录状态，不复制游戏、不将游戏地址拿出来重新打开。无法确定区域时提供手动选择。

## 后台能力边界

常速模式管理 App Nap 及可检测的 WebKit 原生后台调度开关。它不伪装 document.hidden，不替换网页的动画循环；主动失焦暂停的游戏、某些后台动画或 GPU 行为仍可能受限制。开关打开不是已验证 100% 常速的证明。菜单中的测试页面与运行探针可以观察计时器、动画回调、停顿及框架状态；实际游戏推进仍需实机确认。

静音、内置 Inspector 和部分调度开关使用经过运行时检测的 WebKit 非公开接口。系统不支持时明确提示。睡眠与节能分开管理，可单独启用阻止 Mac 空闲睡眠，但不阻止关闭显示器。

## 本地数据

数据只属于此应用，不读取其他浏览器的登录信息。网站权限经明确询问；可以在设置中撤销已保存的摄像头/麦克风选择。没有自动上传页面、密码或诊断。核心程序没有第三方运行依赖。

## 验证

Actions 执行 Swift 测试、隔离世界探针回归测试、arm64 / x86_64 编译、应用打包，以及真实 WKWebView 功能测试。功能测试通过后才上传应用。实际调度结果和截图另外放在 **Pagekeep-test-evidence**，不会把功能测试通过写成所有游戏都已经常速。
